1. git add فایل‌ها را برای ثبت در Commit آماده می‌کند، اما git commit تغییرات آماده‌شده را در تاریخچه Git ثبت می‌کند.
2. فایل .env ممکن است شامل اطلاعات محرمانه مثل رمزها و کلیدهای دسترسی باشد؛ بنابراین نباید آن را در مخزن ثبت کنیم.
3. دستور git diff تغییرات ثبت‌نشده در بخش آماده‌سازی را نشان می‌دهد، اما git diff --staged تغییراتی را نشان می‌دهد که با git add برای Commit آماده شده‌اند.
